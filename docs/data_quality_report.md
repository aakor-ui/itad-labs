# Отчёт о качестве данных (ЛР №3)

## 1. Контекст и входные данные
- **Аналитический вопрос:** Как изменялось потребление энергии и структура энергетического баланса в мире и отдельных регионах с течением времени?
- **Входной S3-путь:** `s3://raw/owid_energy/ingested_on=2026-10-06/owid-energy-data.csv`
- **Смысл строки:** одна строка — это комбинация «Страна (или регион) × Год».
- **Бизнес-ключ:** `country` + `year`.

## 2. Профиль данных
- Всего строк: 23 377, колонок: 131.
- Пропуски: `country` (0), `year` (0), `primary_energy_consumption` (10 122).
- Дубликаты по ключу (`country`, `year`): 0.
- Период: с 1900 по 2025 год.

**Наблюдения:**
1. Данные содержат большой процент пропусков в метриках потребления (около 43%), что характерно для исторических данных — ранние годы не содержат полных замеров.
2. Бизнес-ключ является абсолютно уникальным, что позволяет безопасно использовать его для агрегаций и джойнов без риска размножения строк.
