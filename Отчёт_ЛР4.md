## 3. Выбранный вопрос и модель

**Вопрос (основной из `Project Brief`).** Как изменялись объём потребления энергии и структура
энергетического баланса в мире и отдельных регионах с течением времени?

**Гранулярность.** Одна строка таблицы `energy_balance` — одно наблюдение «страна или регион × год»
из снимка `raw`, прошедшее решения о качестве ЛР № 3. Уровень детализации сохранён: 23 377 строк
`staging` → 23 377 строк витрины, исключённых строк нет.

**Ключ.** `(country, year)` — естественный составной ключ, уникален: 23 377 различных пар, 0 повторов,
0 пропусков. `DISTINCT` не применяется.

**Меры и правила агрегации.** `primary_energy_consumption` (ТВт·ч) суммируется по странам внутри года,
но не вместе с агрегатами; `energy_per_capita` (кВт·ч/чел.) — средняя только с весом `population`;
доли видов топлива (`*_share_energy`, %) не складываются и не усредняются без веса по потреблению;
`count(*)` — число наблюдений с данными.

**Структура.** Одна широкая таблица без отдельных измерений: источник уже денормализован
(страна и `iso_code` в той же строке), внешнего справочника стран в наборе нет, `JOIN` не требуется.
Поэтому проверки сводятся к уникальности ключа `(country, year)`.

Вычисленные поля: `decade` (десятилетие), `is_aggregate` (признак региона/агрегата, `iso_code IS NULL`),
`has_primary_energy` (признак наличия измерения потребления). Остальные меры перенесены без изменения
значений: они уже нормированы в источнике (ТВт·ч, кВт·ч/чел., %). Флаг ЛР № 3
`flag_inconsistent_capita` сохранён.

## 6. Ограничения

1. Данные годовые: внутригодовой динамики нет, вопрос решается на уровне лет и десятилетий.
2. Витрина — снимок источника, а не история изменений; `source_ingested_on` — логическая дата загрузки
   снимка, а не дата события.
3. Пропуски потребления (43 % строк) означают отсутствие измерения, а не ноль: для объёма нужен
   фильтр `has_primary_energy`, а число наблюдений считается отдельно.
4. Строки-агрегаты (`World`, регионы) нельзя складывать со странами — для разделения служит
   `is_aggregate`.
5. Доли видов топлива не суммируются между строками; сравнение структуры корректно для строк
   с полным набором долей (6 379 из 23 377).
6. `primary_energy_consumption` — потребление, а не производство и не выручка.
