# Модель витрины `mart.energy_balance`

Ноутбук: `notebooks/build_mart.ipynb`. Вход — `staging` из ЛР № 3, решения о качестве описаны
в `docs/data_quality_report.md`.

| Артефакт | Путь |
| --- | --- |
| Вход (`staging`) | `s3://staging/owid_energy/source_ingested_on=2026-10-06/staging.parquet` |
| Витрина | `s3://mart/owid_energy/source_ingested_on=2026-10-06/energy_balance.parquet` |

## 1. Модель

**Выбранный вопрос** — основной вопрос `Project Brief`: как изменялись объём потребления энергии
и структура энергетического баланса в мире и отдельных регионах с течением времени?

**Гранулярность.** Одна строка `energy_balance` — одно наблюдение «страна или регион × год» из снимка
OWID Energy (`raw` от 2026-10-06), прошедшее решения о качестве ЛР № 3. Уровень детализации источника
сохранён: 23 377 строк `staging` → 23 377 строк витрины, исключённых строк нет.

**Ключ.** `(country, year)` — естественный составной ключ. Проверено на записанном объекте:
23 377 строк, 23 377 различных пар, 0 повторов, 0 пропусков в компонентах. `DISTINCT` не применяется:
границу строк задаёт источник, а удаление строк изменило бы число наблюдений.

**Меры и правила агрегации.**

| Мера | Единица | Использование в вопросе | Суммируемость |
| --- | --- | --- | --- |
| `count(*)` (`observations`) | наблюдения | покрытие данными по годам и странам | да, по непересекающимся срезам |
| `primary_energy_consumption` | ТВт·ч | объём потребления в срезе | да по странам внутри года; **нельзя** смешивать страны и агрегаты |
| `energy_per_capita` | кВт·ч/чел. | сравнение стран | нет: средняя по странам требует веса `population` |
| `*_share_energy` | % | структура баланса | нет: доли не суммируются, средняя доля — только взвешенная по потреблению |
| `population`, `gdp` | чел., межд. $ | нормировка и сравнение | да по странам внутри года, не вместе с агрегатами |
| `carbon_intensity_elec` | г CO₂/кВт·ч | интенсивность электроэнергетики | только с весом по выработке |

Доли в источнике уже нормированы на первичное потребление: там, где заполнены все девять видов
топлива (6 379 строк), их сумма равна 100.00 %, поэтому доли сопоставимы между странами и годами.
`primary_energy_consumption` пуст в 10 122 строках — пропуск означает отсутствие измерения,
а не ноль; такие строки сохранены и помечены `has_primary_energy = false`.

**Обоснование структуры.** Выбрана одна широкая таблица, без отдельных таблиц измерений:

- источник уже является денормализованной панелью «страна × год»: название страны и `iso_code`
  находятся в той же строке, отдельной сущности для нормализации нет;
- вопрос требует только срезов по стране/региону и году; внешнего справочника (например,
  «страна → континент») в наборе нет;
- в модели нет `JOIN`, поэтому нет и риска размножения строк: проверки сводятся к уникальности
  ключа `(country, year)`.

Отдельная таблица измерения понадобилась бы при появлении внешнего справочника стран; сейчас это
была бы лишняя сущность без аналитической пользы. Поля `*_cons_change_pct`, `*_prod_*`, детальные
`*_elec_per_capita` и другие 90+ полей источника в витрину не перенесены: они не нужны для выбранного
вопроса и остаются доступны в `staging`.

**Итог.** Гранулярность и число строк сохранены, ключ `(country, year)` уникален, пропуски меры
перенесены без искажения и объяснены, флаг ЛР № 3 сохранён, структура баланса согласована (сумма
долей 100 %). Витрина отвечает на выбранный вопрос без обращения к исходному файлу.

**Ограничения.**

1. Данные годовые: внутригодовой динамики нет, поэтому вопрос «с течением времени» решается на уровне
   лет и десятилетий.
2. Витрина — снимок источника, а не история изменений: `source_ingested_on` — логическая дата загрузки
   снимка, а не дата события; повторная загрузка перезаписывает объект за ту же логическую дату.
3. Пропуски в потреблении (43 % строк) нельзя заменять нулём: это отсутствие измерения. Для метрик
   объёма используйте фильтр `has_primary_energy`, а число наблюдений считайте отдельно.
4. Строки-агрегаты (`World`, регионы) нельзя складывать со странами: для разделения служит
   `is_aggregate`.
5. Доли видов топлива не суммируются между строками и не нормируются на население; сравнение
   структуры баланса корректно только между строками с полным набором долей.
6. `primary_energy_consumption` — потребление, а не производство и не выручка: страны-экспортёры
   топлива могут потреблять существенно меньше, чем производят.
